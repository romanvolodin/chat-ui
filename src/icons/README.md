# Иконки

Каждая иконка это отдельный SVG-файл, его можно открыть и править в Figma, Inkscape или Illustrator.
Имя файла становится именем иконки: `arrow-left.svg` → `<BaseIcon name="arrow-left" />`.

Правила:

- холст 24×24 (`viewBox="0 0 24 24"`), поля около 2px;
- иконка нарисована линией, без заливки: фигуры превращаются в контуры при генерации, заливка не поддерживается;
- цвет, толщину линии и скругления задаёт библиотека (`currentColor` и `--chat-icon-stroke-width`), поэтому цвета и толщина в файле на результат не влияют;
- имя файла: строчные латинские буквы через дефис.

После правки файла или добавления нового выполните `npm run icons`: он обновит `src/components/base/icons.ts`. Тесты проверяют, что этот файл не отстал от SVG.
